# سَنَد AI 3.0 — منصة ذكاء اصطناعي محلية على الآيفون

تطبيق iOS يعمل بنماذج GGUF على الجهاز (llama.cpp + Metal)، مع نظام وكلاء وأدوات ومهارات ومساحة عمل ملفات، وMCP، ومزوّدين سحابيين اختياريين.

## ما الجديد في 3.0

| أدوات مساحة عمل (`workspace_*`) | منفّذ | قراءة/كتابة/بحث/حذف/تصدير ZIP داخل مساحة معزولة |

## ما هو غير منفّذ (بصراحة)

- **MLX**: لا يوجد محوّل تشغيل. الكود يفحص `#if canImport(MLXLLM)` ويعرض «غير مدعوم» بدل الادّعاء.
- **موارد MCP وقوالبه وprompts**: العميل الحالي يغطي `initialize` و`tools/list` و`tools/call` فقط.
- **الطباعة/التصدير PDF**: لا يوجد مولّد PDF؛ التصدير ZIP فقط.
- **الاختبارات**: لم تُشغَّل بعد في هذه البيئة (لا Xcode). تُشغَّل في CI.

## البناء

```bash
./scripts/fetch-llama.sh && xcodegen generate && open SanadAI.xcodeproj
```

أو عبر GitHub Actions: كل دفع إلى `main` يشغّل `Build Sanad AI 3.0` وينتج IPA غير موقّع في Releases.

## التثبيت عبر ESign

1. نزّل `SanadAI.ipa` من Releases.
2. ESign ← استورد ← وقّع بشهادتك ← ثبّت.
3. للنماذج 7B فعّل `com.apple.developer.kernel.increased-memory-limit` إن كانت شهادتك تدعمها.
4. النماذج ← اكتشف ← Qwen3 1.7B ← تشغيل.
